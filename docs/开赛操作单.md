## 阶段流转预期日志

```
status=running 阶段=[海选] ...      收割 active_games（并发）
本场结束: finished 标记（gid=...）   每场打完自动回到主循环
status=stage_done 阶段=[…]         晋级轮打完等管理员推进（可能数小时）
status=stage_open 阶段=[…]         确认期：日志出现「已确认出席本阶段」
status=running（新阶段/决赛）       新一轮对局
status=finished                    结束：打印「我的最终排名」
```

## 异常决策树

| 现象 | 判断 | 动作 |
|---|---|---|
| 日志停滞 >3min | 看门狗/网络问题 | 确认进程在；必要时重启 keep_alive（幂等安全） |
| ⚠ 版本自检 BREAKING | 服务器热更 | 拉 /portal/api/guide/version 人工核对（protocol/game 语义） |
| 动作 409 刷屏 | 竞态/窗口已响应 | 自愈（重建快照）；持续刷屏才人工看 |
| 中途退出 code≠0 | 异常 | 看门狗 5s 自动重启；连续重启失败 → 看日志 |
| stage_open 后长期无推进 | 管理员未推进 | 正常空转，继续等（≠异常） |
| 决赛加赛新 game_id | 并列加赛 | 自动出现自动收割，无动作 |
