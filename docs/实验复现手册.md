## 3. 监督训练（小策略网 PolicyNet）

```powershell
# v0 12万 → top1 .741 | v1 104万 → .832 | v3 208万 → .886 | v6 312万 → .884(饱和)
python -m ml.train --data var/ml/samples_1m.jsonl --epochs 10 --batch 1024 --out var/ml/model_v1.pt
python -m ml.train --data "var/ml/samples_1m.jsonl,var/ml/samples_b.jsonl" --epochs 12 --batch 1024 --out var/ml/model_v3.pt
python -m ml.train --data "var/ml/samples_1m.jsonl,var/ml/samples_b.jsonl,var/ml/samples_c.jsonl" --epochs 12 --batch 2048 --out var/ml/model_v6.pt
```

## 4. 传统算法基线（用户路线第一段：最强传统算法 = 向听数速度）

```powershell
python tools/stability.py          # naive/heuristicA/A2/speedA 矩阵 ALL PASS
# Arena 对决（记录于 var/arena/history.jsonl）
python -m arena.runner --combo "speedAx2+heuristicA2x2" --games 36 --rounds 8   # speedA +12.8/局
```

## 5. RL 微调（S4：reward=总分，hu 槽同训，让模型自选速度×打点）

```powershell
python -m ml.rl --ckpt var/ml/model_v4s.pt --out var/ml/model_rl1.pt --games 24 --rounds 8 --iters 200 --lr 1e-4
python -m ml.rl --ckpt var/ml/model_v3.pt  --out var/ml/model_rl2.pt --games 16 --rounds 4 --iters 800 --lr 5e-5
python -m ml.rl --ckpt var/ml/model_rl2.pt --out var/ml/model_rl3.pt --games 16 --rounds 4 --iters 1200 --lr 3e-5 --temp 0.9
python -m ml.rl --ckpt var/ml/model_rl2.pt --out var/ml/model_rl4.pt --games 16 --rounds 4 --iters 900 --lr 5e-5 --opp heuristicA
python -m ml.rl --ckpt var/ml/model_rl4.pt --out var/ml/model_rl5.pt --games 16 --rounds 4 --iters 2000 --lr 3e-5 --temp 0.9
```

## 7. 关键结果汇总（截至 2026-09-04 00:15）

| 阶段 | 结论 |
|---|---|
| 对齐 | 引擎 vs fan-calc 132/132（服务器热更前后两次复核） |
| 监督 | top1 .741→.886；Arena vs heuristicA −9.0→−4.2；胡率 2→5.6% |
| 数据饱和 | v6(312万,.884)≈v3(208万,.886)：208 万饱和 |
| 传统最强 | speedA 胡率 24%、流局 1%；vs A2 +12.8/局 |
| RL | rl2(自v3) 反超起点 +1.09；rl1-5 收敛平台（模型差 ≤1/局≈噪声；vs speedA −25 固定） |
| 平台归因 | CPU 端监督+RL 收敛于 表达力 瓶颈 → 下阶段需 GPU/更大模型/PPO+价值 |
