# 参赛说明（可直接粘贴到申报页面正文）

## 一、程序如何接入官方平台

程序按官方门户接口实现，**全程 AI 自动决策**（出牌 / 碰 / 吃 / 杠 / 胡），**无任何人工干预**：
启动后自动完成「报名 → 到位 → 确认 → 进入对局」，之后每一手由策略层在本地计算并提交，
不读取人工输入、不依赖人工点击。

- 平台地址：`https://10.240.169.190:18080`（默认；可用 `--server` 覆盖）
- 令牌：使用平台派发的**参赛令牌**（报名令牌或参赛令牌），通过命令行参数传入，**不写入源码**

## 二、如何启动

```powershell
# 0) 安装依赖（Python 3.12）
python -m pip install -r requirements.txt

# 1) 免认证自检（不参赛，验证协议/规则/引擎口径）
python run_bot.py --smoke

# 2) 正式参赛（显式指定策略名）
python run_bot.py <参赛令牌> --strategy speedvalue

# 3) 或使用看门狗托管（断线自动重启 + 日志落盘，适合长赛程）
python tools/keep_alive.py <参赛令牌> --strategy speedvalue
```

### 二之补 · 分阶段正式赛（推荐路径）

若赛制是**分阶段/晋级**（官方会给出赛事 id 与令牌）：

```powershell
python -X utf8 var/_ready_1024.py --tid <TID> --token-file <TOK>        # 到位确认（幂等）
python -X utf8 tools/tminus_check.py --strategy <ARM> --token-file <TOK> --tid <TID>   # 赛前总门禁
powershell -ExecutionPolicy Bypass -File var/_switch_to_official.ps1 -Strategy <ARM> -TokenFile <TOK> -TournamentId <TID>
```
该脚本会写官方赛哨兵与 `var/.official_spec.json`，并拉起 `_official_keepalive.py`（负责**报名/到位/阶段确认/进入对局**的自动循环）；
赛后按 `python -X utf8 var/_exit_official.py` 退出官方模式。

> **`<ARM>` 以 `var/_keeper_strategy.txt` 为准**（本项目会按预登记实验逐役择优；示例里写作 `speedvalue`）。

## 五之补 · 模型文件（**重要，提交时别漏**）

`.gitignore` 里排除了 `var/`（里面含令牌/复盘等运行时数据），但**策略网络权重也放在 `var/` 下**
⇒ 直接 `git add -A` 会把模型**漏掉**，导致相关候选臂在别人机器上**静默退化为基线**（不报错、只是变弱）。

当前各臂的模型依赖：

| 策略 | 依赖模型 |
|---|---|
| `speedvalue` / `speedvalueplain` | 无（纯规则） |
| `speedvaluebc` / `speedc151bc` | `var/c073_orig_w2_net.pt` |
| `speedvaluemeld` | `var/c121_meld_net.pt` |
| `speedvaluerank` | `var/c089_ranker_net.pt` |
| `speedvaluebcmeld` | 上面两个 |
| **`speedvaluebaotouv5`**（爆头可达性 V） | **`var/baotou_v1.pt`** |
| **`speedvaluebcv`**（BC + V） | `c073_orig_w2_net.pt` + `baotou_v1.pt` |
| **`speedvaluebaotouvmeld`**（V + 副露） | `baotou_v1.pt` + `c121_meld_net.pt` |
| **`speedvaluebcvmeld`**（BC + V + 副露，部署臂） | `c073` + `c121` + `baotou_v1` |

**提交前请强制加入这四个小文件（合计 ~0.8 MB）**：

```powershell
git add -f var/c073_orig_w2_net.pt var/c121_meld_net.pt var/c089_ranker_net.pt var/baotou_v1.pt
git add -A
git commit -m "submission: hangzhou mahjong bot"
git push
```

**自检**：在干净目录里
`python -X utf8 var/_campaign_ready.py --arms speedvaluebc,speedvaluemeld,speedvaluerank`
应显示每个臂 `模型在场`（若显示 `未加载` ⇒ 模型没提交成功）。

## 六、说明

- 策略可切换：`--strategy <name>`（`python run_bot.py --help` 列出全部可用策略名）；
  本项目以 `var/_keeper_strategy.txt` 记录**当前生产策略名**（逐役择优；撰写本说明时为 `speedvalue`）。
- 程序只使用平台公开信息与自身手牌做决策；不包含任何针对特定对手的硬编码。
