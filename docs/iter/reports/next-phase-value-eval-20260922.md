# 下一阶段设计：价值感知评估函数（2026-09-22）

> 结论先行：**效率类旋钮已经到顶**。本轮（R976~R979）用真实门户复盘 + 2410 配对局的
> rollout 仪表，把 5 条候选全部判负或判平。真实缺口只在一个地方：**胡率**，
> 而胡率的缺口主要在**听牌率**。顶级玩家的优势不是"更会算进张"，而是**更会在
> 效率与价值之间做交易**。因此下一阶段的唯一方向是：**让评估函数含价值项，并用
> 真实/仿真结局标定它**。

## 2. 目标（可测、可验收）

1. 近期：听牌率 53.0% → **56%**（+3pp）；等价地胡率 24% → 26%。
2. 中期：番/胡 1.31 → 1.38（价值取向）。
3. 终点（一个月）：**净分/房由 −21 转正**（当前 c151 在 A/B 上已约 −4.3 净胜/房）。

## 3. 设计：价值感知的**并列层**（不是替换主键）

保持现有主键不动（`(向听, −活等张/听张, ...)`），只在**最小向听集合内**用一个
学习到的价值分数做 tie-break：

```
key = (s, -value_score(state_after_discard), -u, _pref, drawn)
```

- **下行有界**：只影响 `s == smin` 的候选，向听/进张不再被牺牲超过既定 tie-break 范围；
- 与历史上所有成功改动同构（都挂在"并列层"），失败时不会崩坏主链；
- 失败可回退：单文件新臂，不动 `bot/` 既有文件。

### 3.1 特征（全部可在决策时无损获得）

| 组 | 特征 |
|---|---|
| 速度 | 最小向听、活进张数、活等张数、听张种类数 |
| 价值 | 该形在最好等张上的**最高番**、白张数、爆头可达性、对对和/七对可达 |
| 形状 | 对数、连张数、搭子数、孤立牌数 |
| 上下文 | 巡次、河长、自家副露数、已见白张数 |
| 风险（暂缓） | 对手副露/河的放铳代理（本轮证明支出侧已到顶级，先不做） |

### 3.2 标签与数据

- 语料：`var/replays/{server,recent}/*.json`（已 6824 份 / 我方 54584 席局的规模）。
- 标签 A（真实）：该决策后**本局我方得分**（来自 `scores`）。
- 标签 B（仿真、防反事实偏差）：用 `var/_rollout_arm_ev_v2/v3.py` 的固定前缀仿真，
  对同一局面枚举若干个 `smin` 候选弃牌，得到 (和了, 番) 的配对结果。
  ⇒ **这就是"离线策略改进"的合法标签**：同局面、同对手序列，只换我们的动作。
- 划分：**按房间**分 train/test（避免同房泄漏）；报告 test 上的排序准确率与校准。

### 3.3 模型

先用**线性/逻辑回归 + 少量交互项**（≤20 个特征），不用黑箱：
- 可解释（能读出"一张白 ≈ N 张活进张"这类交换率）；
- 可离线快速重训；
- 直接给出**交换率**，正好回答"该不该用宽度换番值"这个本轮反复出现的问题。

### 3.4 验收链（一道都不能跳）

1. 离线：test 上候选排序准确率显著 > 现键（配对 AUC / 一致对数）；
2. 行为：非目标局面**逐位不变**；目标局面改写率在 5~30%；
3. 仪表：`var/_rollout_arm_ev3.py` vs 当前最佳臂，**≥2000 配对局**，和了率为主端点；
4. 冷态延迟：首调用 p99 < 250ms（**禁止再用热态读数**，见 R973）；
5. M=10 行为分歧 ≤5%（`var/_m10_divergence.py`）；
6. 真机 A/B：预登记 + 门禁，跑满 100/150 房再判。

## 4. 里程碑

| 里程碑 | 交付 | 验收 |
|---|---|---|
| M1 特征与数据集 | `var/_value_dataset.py` 导出 (state, action, outcome) 表 | ≥300k 决策样本，按房切分 |
| M2 基线模型 | 逻辑回归 + 交换率报告 | test 排序准确率、与现键对比 |
| M3 新臂 | `bot/speedvalue.py`（并列层替换） | 非目标逐位不变 + 冷态 p99 |
| M4 仪表筛查 | rollout v3 ≥2000 配对局 | 和了率/番和/局显著为正 |
| M5 真机 A/B | 预登记 + 门禁 | 净分/房 > 0 且第一率不降 |

## 5. 纪律（沿用）

- 战役期间**只新增**文件，不动 `bot/` 既有文件、不动阈值/护栏/熔断；
- 延迟证据**一律用冷态首调用**；
- 任何 ≥0.02 以下的番/局差异**不得当作证据**（SE≈0.008）；
- 临时补丁脚本用完改 no-op；机器重活用 `_lowprio`。

⇒ **并列层/阈值层全部出局。**

### 6.3 M3 的具体做法（下一步执行）

把 `bot/speedc151.py` 的第一判据从"最大活进张"换成 **拟合的 V(state)**：

```
_V(state) = w · features            # 线性模型，直接用 M2 的系数起步
candidates = {d : shanten(hand-d) == smin}
pick argmax_d _V(state_after_d)
```

- 目标函数天然包含**番值 / 白 / 向听 / 宽度 / 副露态**，会自动学出"用宽度换番"的斜率；
- 训练标签用 M1 的真实结局，并用 `var/_rollout_arm_ev3.py` 做**同局面配对**校验；
- 必须先做**冷态延迟**测量（fan 计算只在听牌处，其余特征都是 O(1)）；
- 若线性模型不足，再上少量交互项（例如 `ukeire × sh`、`bai × tenpai`），**仍保持 ≤20 个特征**。

### 6.4 R980 给出的第二条线（并行）

"我们太少进入副露态"（巡8：0 副露 47.9% vs 34.2%）不是门控阈值问题（R977 已证放宽是负的），
而是**牌形/机会**问题 ⇒ 在 V 的特征里显式加入"可副露潜力"（对数、两面搭子数、白），
让主判据自己决定"为副露机会保留牌形"的代价。
