## 5. 口径坑（本会话踩出来的，逐条记住）

1. **本地 `replays/auto_*/**.jsonl` 是"一行一事件"的流** —— 必须逐行 `json.loads`，整文件 `json.load()` 会抛 `Extra data` 并静默产出 0 例（我曾因此得出错误结论）；

3. **`timeout` 标记只在门户复盘与本地捕获里都有**（但 1. 的格式差异会骗人）；
4. **本作有两个令牌**：`.global_token`（阶梯）与 spec 的 `token_file`（正式赛）—— 换错文件无效；
5. **`_meld_rate_authoritative.py` 的 `--since` 是死代码**（第 64~65 行 `pass`）且无按臂输出 ⇒ 用 `var/_meld_rate_by_arm.py`；
6. **`meld_from_dec.py` 是块级饱和口径**，**不能**当覆盖率闸门；
7. **`ab_readout` 与 `ab_adopt` 的归属口径必须一致**（前者用排批日志、后者原先用策略名 ⇒ 已修）；
