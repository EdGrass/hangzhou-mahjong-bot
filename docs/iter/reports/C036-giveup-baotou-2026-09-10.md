# C036 SpeedTUG —— 弃胡换爆头（2026-09-10）：本会话最重要的机制发现

> 一句话：**顶级 bot 近一半的爆头，是「主动放弃已经成立的胡牌」换来的**；我们此前
> 100% 的爆头来自吃碰被迫弃牌，弃胡这条路一次都没走过。

## 1. 发现过程（含一次自我纠错）

- 追 544 次爆头到达路径（全量 server 复盘）：

  | 来源 | 次数 | 占比 |
  |---|---|---|
  | 吃碰后被迫弃牌 | 285 | 52.4% |
  | **摸牌后弃牌** | **259** | **47.6%** |
  | └ 其中「弃牌前 14 张本来就是胡牌」 | **248** | **占全部 45.6%** |
  | 我方（u_7a3fba48d70b） | 37 | **37 吃碰 / 0 摸牌** |

- **自我纠错**：此前 R20/C031 我基于「4 面子+白孤在 14 张时即为胡形，故无法被弃牌做出」
  断言爆头结构性不可达——该论证只覆盖了 4 面子型爆头，且**默认胡牌一定不会放弃**，
  因此那个完美先见 oracle 把「胡」写死为最高价值，**从未探索弃胡分支**。结论作废。
- **服务端权威复核**：取 28 个门清样本，用 /portal/api/tools/fan-calc 逐个验证
  → **28/28 服务端认定 hu=true**（我们引擎 28/28 一致），且**多数 fan=1（平胡）**
  → 机制确认：**×1 平胡 → 弃胡 → 弃成爆头形 → 下一摸 ×2 起拿下**。

## 2. 实现（bot/speedtug.py，SpeedTU 派生）

唯一差异：当**已可胡**且**当前番 <= 1**时，若存在一张弃牌能让 13 张变成爆头形，
则**弃胡改打那张牌**；否则照常胡。其余 100% 继承 SpeedTU。

## 4. 为什么这条能改命

得分 ≈ 胡率 × fan（r=0.95，1524 样本回归）。我方 fan 长期锁在 1.10-1.18，
冠军 1.26-1.55，而差距的 70% 来自爆头 ×2。本次把爆头 4.9%→10.8%、fan 1.18→1.38，
**得分代理首次越过池均**——这是把总分从 −6196 打回正数唯一已知的量级来源。

## 6. 干净真机复核（2026-09-10 晚，补充）

房 a_d4f52cfde98e（speedtug，80 席局，全程无中断）：**rank 2 / +56**。

| 指标 | 我方 | 同房最高 |
|---|---|---|
| 听牌率 | 61.2% | 65.0% |
| 胡率 | 25.0% | 30.0% |
| **爆头态** | **2.5%** | 8.8% |

**两房合并的真机 EV 检验（`var/_giveup_ev.py`）**：
- 真机弃胡换爆头样本 = **7 次**；其中 **本局最终由我们胡回 = 5 次（71%）**；
- → 转化率 71% > 50%，**EV 为正**（0.71×2 = 1.42 > 1），但**真机效应明显小于 sim**：
  sim 预测爆头 4.9%→10.8%（+5.9pp），真机实测约 **+2~4pp**（fde98e 的 2.5% 爆头全部来自弃胡）；
- 原因：真机对手比 sim 里的自家 bot 更快，弃胡期间被别家抢先胡的概率更高（7 次里丢 2 次）；
- **结论：C036 真机为"小幅正收益"**（爆头 +2~4pp、番数 +0.05~0.1），
  而非 sim 的 +0.20；两房均 rank 2（+30 / +56），但 n=2 不足以定论，继续累计中。
