# E×4 座位偏倚标定裁决卡（P2b，2026-09-08）

> 假设：测试房"座名对"存在结构性偏倚（历史形态：候选固定青龙/白虎多次为负、
> 固定朱雀/玄武一次为正；座名对占位分解 δ 差 ±5-11/场）。
> 设计：全 speedE（策略无差异）双房（e4a/e4b，独立房间 = 独立令牌/账号池），
> 每场 A=青龙/白虎 对 B=朱雀/玄武 的配对差；若座名对无偏倚 → 期望 δ≈0。
> 会话全程开启决策录制（var/replays/e4{a,b}_*/）+ 席位健康监控。

## 裁决

**座名对（青龙/白虎 vs 朱雀/玄武）无可检出结构偏倚**：合并 T=−0.52/场，
CI 含 0 且窄于 ±2.8。两房各自 ±2-3 的读数 = 房级方差（σ_d≈11-14 → 单房
SE≈√40≈2），**房际翻转（k1 +0.7 vs w2 −4.7 等历史形态）可用纯方差解释**，
无需"座位偏倚"假说。

## 推论（改写历史结论的可信度）

1. **历史各会话（n≤60）判定力严重不足**：σ≈11-14、δ=2 需 n≈150-190 →
   大多数 DRAW/LOSE/小正值与"真实效应≈0 + 噪声"完全相容；
2. 候选固定座对并非系统性偏倚源（无结构偏倚）——历史负结果仍不可证伪
   微调族的 ±2 级弱效应，但 oracle v2 已示其分歧幅度 ≤5.3%、预期 |δ|<1
   （低于可判线与决策价值线）→ 平衡复核的期望价值为负，维持封存；
3. 今后 A/B 仍按平衡设计执行（成本低、免疫未知房级效应），但**判据线按
   σ_d 实测（9-14）与 n≥150 规划**——与 docs/自迭代方案.md R11 修订一致。
