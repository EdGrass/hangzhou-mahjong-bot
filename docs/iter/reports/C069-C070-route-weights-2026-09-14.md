# C069/C070 目标牌型（route）权重再估计 —— 舍牌 + 吃碰（2026-09-14）

## 用户的判断：舍牌/吃碰权重在各种目标牌型下都不对 —— 先量化

### 1) 舍牌：与顶级 bot 的一致率按手牌形态分桶（89,729 个顶级决策）

脚本 `var/_c069_diag.py`（用 `var/_bc_data_c068.npz` 的 BASE＝我们的 `_best_discard_t`
选择，Y＝顶级实际弃牌）：

| 分桶 | 样本 | 我们 vs 顶级一致率 |
|---|---|---|
| 全部 | 89,729 | 65.8% |
| **对子 ≥5（七对近）** | 2,022 | **48.7%** ← 最差 |
| 对子 3–4 | 18,942 | 59.1% |
| **副露 = 0（门清可七对）** | 46,056 | **60.5%** |
| 副露 1 / 2+ | 28,032 / 15,641 | 68.9% / 75.8% |
| 单花色 ≥70%（清一色近） | 7,378 | 73.7% |
| 花色分散 | 39,318 | 63.3% |
| 白 ≥2 | 6,332 | 68.7% |
| 巡目 ≥8 | 15,186 | 74.6% |

→ **结论：现有弃牌权重（`speedt._pref`：孤字0/孤数1/拆顺2/拆对3/白4）是路线无关的单一偏好表，
在「七对近」局面只有 48.7% 与顶级一致、门清局面 60.5%，明显低于全局 65.8%；**
而番值恰恰由分支倍率决定（平胡 ×1 / 七对 ×2 / 豪华七对 2^(n+1)，再叠 4白/爆头/链 ×2），
所以这些局面的分歧直接对应番值损失。

## 做出的两个优化

### C069：弃牌模型加入 route 特征（七对/豪华/爆头/四白/清一色/一般形）

- `bot/c069routes.py`：22 维路线特征（训练与在线同源）
  一般形向听/听牌数/进张、**七对专用向听**、对数、**四张组数（豪华七对）**、刻子数、单张数、
  **爆头判定**（`is_baotou`，仅在听牌局面才调用——性能由 20ms/次降到 0.03ms）、四白进度、
  最大花色集中度、字牌占比、分支倍率估计；
- `var/_c069_discard_train.py`：每候选 65 维 = 在线 `_state_feat`(43) + route(22)，
  行 = [候选65, 动作34, 候选−基线差65, 动作差34] → din=198；训练/门禁见下；
- 定位：不是改规则阈值，而是**让网络自己估计「这条路线值多少」**（用户说的权重估计）。

### C070：吃碰判据由「学出来的模型」接管（相对基线优势）

- `bot/c070meld.py`：共享特征/构造（公共块 96 + 选项块 47 = 143 维/选项）；
  两个选项 = {应, 过}，基线 = C045 的 `want_claim_strict_meld`；
- `var/_c070_meld_train.py`：19,337 个可用窗口，验证集
  **模型一致率 85.0% vs 规则 82.8%（+2.1pp）**；分桶：
  **碰 +6.1pp**（83.7% vs 77.5%）、巡目>8 +5.4pp、吃 −0.5pp（噪声）；
- `bot/speedc070.py`：`C070Policy` = C068-lo0 弃牌 + 学到的副临判据（只有与基线不同
  且分差 > `meld_margin` 才改判；模型缺失时行为与 C068-lo0 完全一致）。

## C069 门禁结论：**rejected**（一致率涨、棋力降 —— 又一条 C040 型教训）

补上 `bot/speedc069.py` 后重跑 40 房门禁（模型确实被调用：`used=3675 chg=744 fb=0`）：

| 臂 | 强场 | 混合场 |
|---|---|---|
| C045（基线） | +2.4 | +10.0 |
| C068-lo0（当前生产候选） | **+19.8** | **+32.0** |
| C069（route 特征，验证一致率 69.7% vs 65.5%） | **+0.9** | **+14.7** |

→ **route 特征让模型更像顶级 bot（七对近桶 +3.2pp、对子3-4 +6.0pp），但得分明显变差**。
机理解读：把「七对/门清路线进度」喂给网络后，模型学会了模仿顶级在路线上的选择，
而其中相当一部分（在 sim 的对手结构与赔付下）不是增益——与 C040 的「风格 ≠ 因果增益」同源。
**结论：C069 归档不采用；C070（弃牌沿用 lo0，只把副露判据换成学出来的模型）保留并上线。**
