## 3. ★ 样本量（本文最重要的数字）

`SE(Δ) = 205·√(2/n)`（实测房级 SD=205）；要 `t=1.96` 采用 `Δ=+28.5`：

**n = 2·(1.96 × 205 / 28.5)² ≈ 398 房/臂 ≈ 8.3 天**（2 房/臂/小时）。

| 目标 | 需要 |

| 100 房/臂（起步判） | 只能采用 `Δ ≥ 57 分/房`（远大于期望）⇒ **100 房不可能采用**，只能触发 futility / 中期 |

| 延期规则 | 100 房时若 `0.60 ≤ t < 1.96` ⇒ 延到 398 房；`t < 0.60` ⇒ null |
